# CSAPP Labs

Personal practice for CMU 15-213 (CSAPP). Solutions are my own work and are for reference only.

In each lab directory, the `*lab-handout/` folder contains my own completed code (the lab is done), while the original framework is kept in the `*lab-handout.tar` archive.
